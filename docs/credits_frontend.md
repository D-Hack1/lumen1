# credits_frontend.md

_Owner: Abhinav_

Every image shown in the app body, with its credit line. The source of truth for the on-screen text is
`web/src/content/credits.ts` (rendered by `CreditLine`); this file mirrors it with the open items.
Rules (FRONTEND_BUILD_GUIDE §3.3): local files only (no hotlinking, works offline); NASA/LROC preferred; never a NASA
logo or insignia; never an AI-generated image presented as real; ISRO imagery only with its terms recorded.
