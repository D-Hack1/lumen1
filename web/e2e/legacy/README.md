# e2e/legacy

Specs for the old cockpit/compare shell (`src/App.tsx`, `src/app/views/*`). That shell is no longer mounted (the live app is the four pages in `src/features/pages`), so these are **not run** by `npm run e2e`. Kept for reference; to run them, mount the old shell again (see git history of `src/main.tsx`) and point a Playwright config at this folder.
