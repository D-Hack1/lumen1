
# data-mock

Owner: Nived. **Fake values, same folder structure as `data/`.** Generated by `python3 web/src/mocks/make_mock.py`
(stdlib only, deterministic). Do not hand-edit; change the script and regenerate. Switch with `VITE_LUMEN_DATA=mock|real`.

All binary files are **little-endian**. Every JSON header has `mock: true`. **Masks and sigma follow `contracts/data_masks.md`
v1.0.0 exactly** (Shiva Shakthi). The catalog follows `contracts/data_catalog.md`. Everything else is still a **draft** built from
PLAN_FINAL §6 + R3 delta D-11 (those contracts are empty or short); reconcile when the owners fill them in.

| File | Format |
|---|---|
| `ephem/ephem.{bin,json}` | **Mirrors Gowri's real files** (`pipeline/ephem/ephemeris.py`): raw LE float32 `[count, 12]` (`sun_pos[3] sun_vel[3] earth_pos[3] earth_vel[3]`, km, km/s) + sidecar with `version:"1"`, `shape`, `dtype`, `fields` (4 groups), `units`, `sha256`, `start_utc`, `end_utc`, `start_et_tdb`, `step_seconds`, `frame:"MOON_ME_DE421"`, `aberration_correction`, `kernel_provenance`. **Mock step is 6 h** (real: 3600 s); loaders read `step_seconds`. Mock range 2023-01-01 → 2031-01-01. |
| `dsn/dsn.{bin,json}` | Same format. **int16 = round(el_deg·2)**, valid [-180, 180], `scale 0.5`, `offset 0` (data_dsn.md). Mock shape `[count, 3]` time-major, `fields` = station ids; the loader also accepts `[3, count]`. Mock cadence 1800 s (real: 600 s). |
| `catalog/sites.json` | **Mirrors Gowri's real `build_catalog.py` output**: `latitude_deg`, `longitude_deg_east`, `coordinate_frame: MOON_ME_DE421`, `landing_coords`/`target_coords` as `{lat, lon, source}` (either may be null), terrain info nested under `terrain` (`status`, `mask`, `sigma`, `pad`, `psr`, `near_field_res_m`), `rotation_matrix` rows **(east, north_reference, up)**, `touchdown_utc` + `touchdown_precision`. Real tiers are all `pending` until the terrain run; the mock uses A and C so both paths are exercised. Blue Ghost is Tier C. |
| `catalog/sparklines.{bin,json}` | Shared binary-sidecar format. uint8 percent, shape `[site, 2 (sunlit, link), 400 days]`. Extras `sites`, `start_utc`, `days` are DRAFT (not in data_catalog.md yet). |
| `terrain/masks/<id>.{bin,json}` | **Contract v1.0.0.** 64-byte `LUMENMSK` header, then float32 elevation `(4,3600)` then float32 distance km `(4,3600)`, height-major; 115,264 bytes. Sidecar `version` is the string `"1.0.0"`. **`cy3_shiv_shakti` has NaN in bins 3598, 3599, 0, 1 (all heights) on purpose** to test NaN preservation and the circular range query (listed in `mock_nan_bins`). Mask contains a narrow ridge spike on purpose. |
| `terrain/sigma/<id>.{bin,json}` | **Contract v1.0.0.** 64-byte `LUMENSGM` header, float32 `(4,3600)` degrees; NaN exactly where the mask is NaN. Sidecar `source: "default"` (no `clone_count`). |
| `terrain/sigma/sigma.json` | tier defaults + Tier-B calibration table (draft; not in the contract). |
| `terrain/pad/<id>.json` | **Contract 0.1.0** (data_terrain_misc.md §1): `ground_normal_me`, `slope_deg`, `downhill_aspect_deg`, `uphill_az_deg`, `z0_m`, `d_min_m`, `near_field_resolution_m`, `under_resolved`, `plane_fit`, `dispersion_slope_stats`. |
| `terrain/dispersion/<id>.{json,bin}` | **DRAFT layout** (contract leaves it open): 11×11 uint8 slope (0.1°), 50 m spacing. |
| `terrain/tierb/index.json` + `tiles/s90_000.bin` | one 8×8-node tile, 2 km spacing; `sections` give byte offsets for `lat_deg, lon_deg, mask (uint8·0.05+offset), slope_deg, downhill_aspect_deg, z0_m`. |
| `terrain/psr/psr_distance.{json,bin}` | 80×80 uint16 km·0.01 raster, polar stereographic. |
| `terrain/layers.json` + `terrain/layers/*.png` | **Contract 0.1.0 paths** (descriptor at `terrain/layers.json`, not inside `layers/`). Per layer: `layer_id`, `name`, `extent` (`80_90S`/`85_90S`), `filename`, `projection`, `legend_stops [{value,label,hex}]`, `source_citation`. 5 layers × 2 extents, 256 px. Projection params are **DRAFT** (contract 5.4 not frozen): `r = 2R·tan(colat/2)`, `x = r·sin(lon)`, `y = r·cos(lon)`, `px = cx + x/mpp`, `py = cy − y/mpp`. |
| `terrain/regions.json` | Contract §6: `region_id`, `name`, `centroid_lat_deg`, `centroid_lon_deg`, `svg_path` (km, y flipped), `projection`. Names are labelled MOCK. |
| `terrain/summaries/<id>.json`, `terrain/manifest.json` | **Contract 0.1.0** (§7): `files_present`, `pad_headline`, `psr {…, source_classification}`; Tier C = `tier: "pending"` with null entries. |
| `golden/golden_set{1,2}.json` | **empty `cases`** on purpose — parity tests must skip until Gowri's real vectors land. |
| `validation/report.json` | G0–G13 placeholders. |
